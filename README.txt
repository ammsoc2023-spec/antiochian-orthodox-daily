Antiochian Orthodox Daily 2026 – offline PWA (EN / عربي)
Static files only. Serve this folder over HTTPS (any static host). Nothing has been published.
Open the URL on the phone once (it caches the whole calendar), then:
 iPhone (Safari): Share → Add to Home Screen.   Android (Chrome): menu ⋮ → Install app / Add to Home screen.
Data: data/2026-MM.json (one per month, lazy-loaded), data/index.json (search), data/about.json.
Text is exported from the same day model as Antiochian_Calendar_2026_Full_Year_Daily_EN-AR.docx (tools/export.py).
To add official Arabic reading texts later: put data/official/YYYY-MM-DD.json in the project (same schema as src/aoc_readings.json), add the English X<n> line to content/MM.txt, and rebuild.
